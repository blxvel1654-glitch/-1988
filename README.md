# オートレースAI試走分析

## GitHub Pagesへの公開
1. GitHubで `autorace-ai` という名前のPublicリポジトリを作成します。
2. `index.html` をリポジトリ直下にアップロードします。
3. Settings → Pages → Build and deployment で `Deploy from a branch` を選びます。
4. Branchを `main`、Folderを `/(root)` にして Save します。
5. 公開後は `https://あなたのGitHubユーザー名.github.io/autorace-ai/` で開けます。

## 現在の実装範囲
- 動画アップロード・再生・フレーム保存
- 映像から予想した試走タイムの入力欄
- 公式発表の実際の試走タイム入力欄と誤差表示
- 今回の出走メンバーとの過去対戦勝数・対戦数入力欄
- 選手評価、買い目候補、購入予算、結果・収支記録

注意：動画からの試走タイム自動推定、公式サイトからのデータ自動取得、選手ごとの対戦履歴の自動照合は未実装です。現状は動画を見て予想タイムを入力し、公式出走表・成績を確認して手入力する試作版です。GitHub Pagesは静的サイトなので、AI動画解析や外部データ連携には別途バックエンド/API等が必要です。
